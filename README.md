# CtrlRelay

Control your PC via Telegram currently in pre-release phase

[![Pre-release](https://img.shields.io/badge/release-pre--release-yellow)](https://github.com/Ma7adi805/CtrlRelay/releases/latest)

## Features

1. Control your laptop remotely
2. Upload files through Telegram
3. Type and control keyboard remotely
4. Additional functionality coming soon

## Getting Started

1. Visit the [releases](https://github.com/Ma7adi805/CtrlRelay/releases/latest) page
2. Download the latest exe file
3. Run the executable it will generate a env file
4. Edit the env file with your Telegram bot token and chat ID
5. Run the program again use Ctrl+C in terminal to stop if needed

## How to Use

1. Go to https://github.com/Ma7adi805/CtrlRelay/releases/tag/v0.1.0-beta
2. Download the exe file
3. Execute the program creates .env file automatically
4. Open .env file and add your Telegram credentials
5. Restart the application
